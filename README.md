# Mahu — reference-faithful website

This package uses the supplied long-page artwork as the exact visual source, so the original typography, spacing, imagery and composition are preserved instead of being re-created with a different font.

Included:
- `index.html` — complete website
- `assets/reference-design.jpg` — supplied design image
- subtle entrance/parallax/ambient animations
- responsive mobile + desktop presentation
- page title/brand metadata set to **Mahu**

## Publish
Upload the whole folder to any static hosting service, keeping the `assets` folder beside `index.html`.

For a live public URL with editing/access, connect a hosting service such as Replit and import this folder.
